Privacy Policy

Last updated: March 5, 2026

NBA Stables is a free stats site. We do not require user accounts.

What We Process

  • Basic technical request data (for example IP address, user agent, referrer, response status) in server logs.
  • Usage analytics events through self-hosted Umami, only when you accept analytics cookies.
  • Local browser storage needed for app behavior (including your cookie consent choice).

Why We Process Data

  • Operate, secure, and troubleshoot the service.
  • Measure site usage and improve performance and content.

Legal Basis

Where applicable (EEA/UK), we rely on legitimate interests for necessary operation/security and consent for non-essential analytics cookies.

Retention

Logs and analytics are retained only as long as reasonably needed for operations, reliability, and abuse prevention.

Third-Party Sources

NBA Stables displays data from third-party sports data sources, which may be delayed or incomplete.
