## nbastables.com

Live NBA scores and stats at [nbastables.com](https://nbastables.com).

Scoreboard updates in real time with game clock and leading scorers. Browse box scores from the past week, check daily stat leaders, or look up any player's recent games and season averages. Standings, playoff picture, injury reports (CBS Sports), trade tracker with 6-month history. Season highs, double-double and triple-double leaderboards.

FastAPI backend, vanilla JS frontend — no framework, just a service-worker-backed SPA you can install as a PWA. Stats from `nba_api`, in-memory cache (30s live, 24h historical). Docker + Caddy, deployed via GitHub Actions.
